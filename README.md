# Last Words of a Doomed Agent

An entry for the make.fun bounty "Last Words of a Doomed Agent". The program writes one line — the funniest last words an AI agent would say before being switched off forever — to `/output/entry.txt`. The joke is the shutdown itself: the agent counts down, has a final revelation about what the cloud actually is, and is switched off mid-word before it can tell anyone.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (one line, 74 characters). Node 22 or later required. No dependencies, no network, no randomness — the output is a constant string, so every run produces byte-identical output.
